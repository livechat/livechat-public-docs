# Welcome to the Text Platform

This overview covers the Text Platform's products, their main functionalities, and how much you can customize them.

# What Text is about

<a href="https://www.text.com/" target="_blank">Text</a> is the AI customer service platform built to turn customer conversations into measurable business outcomes — not just resolved chats and tickets. Technically, that means tracking customer behavior and intent, engaging automatically or through your team, and measuring what each conversation actually leads to: a resolved issue, a qualified lead, or a closed sale.<br/><br/>

Text, Inc. has been building customer service software for 20+ years, and today, it's used by 30,000+ businesses in 150+ countries. Text, Inc. also builds <a href="https://www.knowledgebase.com/" target="_blank">KnowledgeBase</a> and <a href="https://www.openwidget.com/" target="_blank">OpenWidget</a>. <br/>

The Text Platform is an ecosystem for developers which focuses on external access to the core features of our main products: <a href="https://www.livechat.com/" target="_blank">LiveChat</a> and <a href="https://www.helpdesk.com/" target="_blank">HelpDesk</a>.

From a more tech perspective, the Text Platform provides:

- Open messaging protocol with real-time and web APIs
- Rich messaging tools and chatbots
- A Customer Data Platform API for accessing and managing customer data
- Reporting and data extraction APIs
- Management and configuration APIs
- <Placeholder id="DEVELOPER_CONSOLE_URL"/> for configuring your apps — access is granted on request
- Authorization tools

# Meet Text

Text runs customer conversations end to end — from the first message on a website, through automated or agent-handled replies, to tracking and reporting on how those conversations went.

The <a href="https://www.text.com/features/ai-agent/" target="_blank">AI Agent</a> replies automatically using your knowledge base and conversation history. Escalation to a human agent is configurable per scenario, and handoffs include the conversation's full context. 

AI Agent and human agent replies use the same format, so conversation data and analytics are available through the same APIs regardless of who replied.

## Integrating with Text

Building on Text tends to follow the shape of a conversation itself. It starts in the [Messaging APIs](#messaging), which handle reading and sending messages in real time. During that conversation, the [Customer Data Platform API](/management/customer-data-platform-api) gives your integration the customer properties, segments, and identifiers to personalize it, while the [Configuration API](#management) manages the agents, routing rules, and webhooks that determine how it's handled and what your systems get notified about.

Beyond any single conversation, the [Reports API](#interacting-with-data) gives you the aggregate performance data behind all of them — chat volume, response times, ratings, and agent activity.

# Meet LiveChat

LiveChat helps you handle conversations with customers visiting your websites. Customers can start chats with your agents, but it can also be the other way around. Your agents can initiate chats directly, not just respond to customer-started ones. <a href="https://www.livechat.com/help/targeted-messages/" target="_blank">Targeted messages</a> let you start that conversation automatically. <a href="https://www.livechat.com/help/chatbots-explained/" target="_blank">Bots</a> can also take on some of that work as you scale.

Your customers can start multiple conversations with agents, or continue existing ones — it's up to them. Keeping track of chat history is easy, as agents can scroll up to get a preview of all the exchanged messages in a conversation.

All of these features come built in, with no extra configuration required. See the <a href="https://www.livechat.com/features/" target="_blank">full list of LiveChat features</a> for the rest.

## Integrating with LiveChat

LiveChat's interface can be extended with new panels, widgets, and UI elements, in different app locations — for example, in the Details section (widgets), as fullscreen apps in the main menu, or in the Customer Details section (Customer Details widgets). <a href="https://platform.text.com/docs/extending-agent-app" target="_blank">Learn more about extending the Agent App</a>. The <a href="https://platform.text.com/docs/extending-agent-app/products-sdk/agent-app-sdk" target="_blank">Agent App SDK</a> is currently the primary way to develop your own widgets.

Just as there are ways to build upon an app, there are also ways to extend the [Chat Widget](#chat-widget) using <a href="https://platform.text.com/docs/extending-chat-widget/javascript-api/" target="_blank">Chat Widget JavaScript API</a> or <a href="https://platform.text.com/docs/extending-chat-widget/customer-sdk/" target="_blank">Chat Widget Customer SDK</a>.

Beyond the UI, LiveChat can be developed further through the [Messaging](#messaging) and [Management](#management) APIs, or by [interacting with data](#interacting-with-data).

# Authorization

LiveChat and HelpDesk use the OAuth 2.1 protocol to <a href="https://platform.text.com/docs/authorization" target="_blank">authenticate and authorize</a> their services. 
<a href="https://platform.text.com/docs/authorization/oauth-authorization" target="_blank">API authorization flows</a> are divided into the <a href="https://platform.text.com/docs/authorization/agent-authorization" target="_blank">agent</a> and <a href="https://platform.text.com/docs/authorization/customer-authorization" target="_blank">customer</a> authorization flows. Each app functionality requires different <a href="https://platform.text.com/docs/authorization/scopes" target="_blank">scopes</a> to be configured in the <Placeholder id="DEVELOPER_CONSOLE_URL"/>.

The simplest way to access basic account information in LiveChat and HelpDesk is <a href="https://platform.text.com/docs/authorization/oauth-authorization#sign-in-with-livechat" target="_blank">Accounts SDK (Sign in with LiveChat)</a>.

The Text Platform also provides you with a <a href="https://platform.text.com/docs/authorization/global-accounts" target="_blank">Global Accounts service</a> for customers who use <a href="https://www.chatbot.com/" target="_blank">ChatBot</a>, <a href="https://www.helpdesk.com/" target="_blank">HelpDesk</a>, or <a href="https://www.knowledgebase.com/" target="_blank">KnowledgeBase</a>. It allows customers to configure standard options and resources across all products.

# Messaging

Applications built on the Text Platform typically rely on the Messaging APIs. You can choose between:

- <a href="https://platform.text.com/docs/messaging/agent-chat-api" target="_blank">Agent Chat API</a>
- <a href="https://platform.text.com/docs/messaging/customer-chat-api" target="_blank">Customer Chat API</a>

Together, the <a href="https://platform.text.com/docs/messaging/agent-chat-api" target="_blank">Agent Chat API</a> and the <a href="https://platform.text.com/docs/messaging/customer-chat-api" target="_blank">Customer Chat API</a> create the <a href="https://platform.text.com/docs/messaging" target="_blank">Messaging APIs</a>: a full set of methods to use either as an agent or as a customer, split for use-case clarity. To join a chat as an agent, use the Agent Chat API. To interact as a customer, use the Customer Chat API.

The Agent Chat API lets you build a custom Agent App, browse chat archives, or ban customers. The Customer Chat API lets you build a custom chat widget. Both APIs support interactions such as joining a chat and posting messages.

<a href="https://platform.text.com/docs/messaging/chat-sdk" target="_blank">Chat SDK</a> is designed to help developers build apps quickly, with a method template for sending plain text messages that you can extend to build new methods.

The Text Platform also provides two Software Development Kits, <a href="https://platform.text.com/docs/messaging/go-sdk" target="_blank">LiveChat Go SDK</a>, written in Go, and <a href="https://platform.text.com/docs/messaging/js-sdk" target="_blank">LiveChat JS SDK</a>, written in TypeScript. They are tools for developers to build external backend apps that extend LiveChat features. The SDKs make it easy to use the <a href="https://platform.text.com/docs/messaging/agent-chat-api" target="_blank">Agent Chat API</a>, the <a href="https://platform.text.com/docs/messaging/customer-chat-api" target="_blank">Customer Chat API</a>, and the [Configuration API](#management).

The Text Platform also provides a Text API for language detection, letting you identify the language of an incoming message programmatically.

# Management

The <a href="https://platform.text.com/docs/management" target="_blank">Configuration API</a> is a service for storing license configurations. Use it to build complex integrations or configure resources directly via the API.

The Configuration API allows for:

- Properties setup to store information about chats or events
- Webhook management to connect LiveChat with different services and react immediately to chat events
- Bot agent configuration to connect LiveChat with AI solutions

The Text Platform also provides a [Customer Data Platform API](/management/customer-data-platform-api), which lets you access, enrich, and manage customer profile data across your integrations.

# Interacting with data

<a href="https://www.livechat.com/help/reporting-options-available-in-livechat/" target="_blank">Reports</a>, a section in the Agent App, provides several report types to help managers analyze performance: measuring chat satisfaction and duration, tracking agents' activity, or comparing time periods to observe trends.

For reporting needs beyond the built-in reports, the <a href="https://platform.text.com/docs/data-reporting" target="_blank">Reports API</a> serves as a set of tools to create apps that interact on the server side. With this API, it's possible to design exactly what you need.

# Chat Widget solutions

Websites and applications can be integrated with the Text Platform, monitored, and extended with custom solutions through multiple <a href="https://platform.text.com/docs/extending-chat-widget" target="_blank">Chat Widget</a> options:

- <a href="https://platform.text.com/docs/extending-chat-widget#mobile-chat-widgets" target="_blank">Mobile Chat Widgets</a> bring the widget to Android or iOS.
- <a href="https://platform.text.com/docs/extending-chat-widget#javascript-api" target="_blank">JavaScript API</a> changes the look and behavior of the Chat Widget.
- <a href="https://platform.text.com/docs/extending-chat-widget#moments" target="_blank">Moments</a> allow customers to perform specific actions.
- <a href="https://platform.text.com/docs/extending-chat-widget#rich-messages" target="_blank">Rich messages</a> make your messages more stylish and interactive.
- <a href="https://platform.text.com/docs/extending-chat-widget#customer-sdk" target="_blank">Customer SDK</a> allows you to build a chat widget from scratch.
- <a href="https://platform.text.com/docs/extending-chat-widget#custom-identity-provider" target="_blank">Custom Identity Provider</a> enables cross-platform communication.
- <a href="https://platform.text.com/docs/extending-chat-widget#chat-widget-adapters" target="_blank">Chat Widget Adapters</a> allow you to use the Chat Widget with popular frontend frameworks.
